# Hospital Management System

A university-project prototype based directly on the supplied Hospital Management System scenario.

## Features
- Existing patient retrieval/search
- New patient registration/update
- Doctor list and availability
- Appointment request
- Availability checking
- Appointment confirmation
- Patient notification (simulated by confirmation toast)
- Appointment cancellation by assistant
- Dashboard statistics
- Data persistence with browser localStorage

## Run
Open `index.html` in a modern browser.

No server or installation is required for this prototype.

## Scenario mapping
Patient -> request appointment
Assistant -> retrieve/update patient details
System -> check doctor availability
Assistant -> confirm appointment
System -> notify patient
Assistant -> cancel appointment at any time
